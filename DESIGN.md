# Hybrid website proposal

Mono is the visual base. Preserve its black canvas, Public Sans, narrow sidebar, floating mobile navigation, open portfolio history and allocation, and grouped asset panels.

Palette: canvas #000000, panel #141414, control #1D1D1D, border #303030, text #F5F5F5, secondary #A3A3A3. Existing semantic gain/loss colors and illustrative marks remain.

Borrow from Mono Opus: persistent amount hiding, subordinate headline decimals, compact imports and account lists, and plain document-style legal pages. Holdings show monetary gain and percentage together. Reuse Mono page headers, spacing and controls for a consistent composition.

```
Mono sidebar   Portfolio                    Hide amounts  Import
               Large total with quiet decimals
               Open history                 Allocation
               Asset group                  Asset group
               Recognizable holdings with value + gain + return
```

This preserves the user's preferred visual direction. The hybrid does not replace either source proposal and has no independent rating. All changes are confined to this worktree. The comparison uses sample data, illustrative logos and substituted authentication.
